Descrição detalhada

Lê e interpreta o módulo sensor de vibração digital SW-420.

O módulo SW-420 possui um comparador (LM393) que entrega uma saída digital: em repouso a saída fica em um nível lógico e, ao detectar vibração, passa para o nível oposto. A sensibilidade é ajustada no potenciômetro do módulo.

No kit STM32MP1-DK1 o pino de sinal é ligado a uma entrada do ADC, portanto a leitura é feita pelo subsistema IIO do Linux, no arquivo /sys/bus/iio/devices/iio:device0/in_voltageX_raw. A classe converte o valor bruto do ADC em tensão e decide se há vibração comparando essa tensão com metade da tensão de referência.

Exemplo de uso:

SensorVibracao sensor(4); // sensor ligado ao canal in_voltage4_raw
bool vibrando;
if (sensor.vibracaoDetectada(vibrando)) {
// usa o resultado
}

◆ medirIntensidade()

bool SensorVibracao::medirIntensidade ( int amostras,
int intervaloMs,
double & intensidade ) const

Mede a intensidade de vibração em uma janela de várias amostras.

A vibração gera pulsos curtos na saída do sensor, e uma única leitura pode perdê-los. Por isso esta função lê várias vezes e informa em que porcentagem das leituras houve vibração.

Parâmetros
amostrasQuantidade de leituras (deve ser maior que zero).
intervaloMsPausa entre leituras, em milissegundos.
[out]intensidadePercentual (0 a 100) de amostras com vibração.
Retorna
true se todas as leituras foram bem-sucedidas; false se alguma falhou ou se amostras não é positivo.
